# Wartorn Companion

Tampermonkey userscript for the [Wartorn](https://wartorn.spiffer10.com) Torn faction dashboard.

Published on GreasyFork: https://greasyfork.org/en/scripts/595166-wartorn-companion

This repo exists so GreasyFork can sync the script directly from source
instead of requiring a manual copy-paste publish on every update. The
canonical copy lives in the main Wartorn project; this repo mirrors just
the one file.
